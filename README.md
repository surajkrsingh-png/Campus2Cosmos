# Campus2Cosmos

Campus2Cosmos is a responsive educational website designed for home tuition services. It provides information about mentors, student activities, academic programs, and contact options through a modern and engaging user interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Maps Embed API
- EmailJS (planned integration)

## Features

- Responsive Design
- Interactive Navigation Menu
- Gallery with Category Filters
- FAQ Accordion
- Contact & Inquiry Form
- Google Maps Integration
- Mobile-Friendly Layout
