# Campus2Cosmos

A responsive educational platform designed to connect students and parents with qualified tutors for home tuition and classroom learning. The website provides information about services, achievements, learning environments, and allows users to book free demo classes through an integrated inquiry system.

## 🌐 Live Website

https://surajkrsingh-png.github.io/Campus2Cosmos/

---

## 📖 Project Overview

Campus2Cosmos was developed to create a strong digital presence for a tuition and educational services platform. The website focuses on providing a clean user experience, responsive design, and an easy way for parents and students to connect with tutors.
